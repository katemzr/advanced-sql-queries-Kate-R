# advanced-sql-queries-Kate-R

○ What did you learn?
I learned more advanced queries for SQL and used them in MySQL Workbench. Some of the advanced queries included JOINs, like INNER JOIN and LEFT JOIN, and SubQueries, such as Scalar subqueries, Column subqueries, and Table subqueries. We also learned GROUP BY, HAVING & WHERE Clauses, and Aggregate Functions.

○ What was most challenging?
One of the bigger challenges for me in this lesson was understanding the order of operations in the subqueries and getting the syntax correct.
